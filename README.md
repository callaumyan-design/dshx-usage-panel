# dshx-usage-panel

A DSH settings page showing the DeepSeek account balance and today's token usage.

A plugin for [DeepSeek Harness](https://github.com/callaumyan-design/dsh) (DSH).

## Install

Add it to your DSH profile as a local package (`file:` path) or install it from this repository, then restart DSH.
